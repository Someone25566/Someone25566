## ◈ ABOUT ME

I'm **Youssef Sameh**, a multidisciplinary creator and developer working at the intersection of **design, technology, and creative direction**.

I enjoy transforming ideas into functional digital experiences — from visual identities and user interfaces to mobile applications and full-stack systems.

My approach combines creative thinking with technical execution, focusing on products that are visually refined, intuitive, and built to scale.

- **Creative:** Graphic Design, Visual Identity, Composition and Visual Direction.
- **Development:** Android Applications, Full-Stack Systems and API Development.
- **Engineering:** Database Architecture, Backend Systems and Infrastructure.
- **Direction:** Video Direction, Motion Design and Creative Production.

> "I speak code and sometimes on stage."
